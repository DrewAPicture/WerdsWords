Just released v1.1 of [Download Shortcode](http://wordpress.org/extend/plugins/download-shortcode/), with added support for subdirectory WordPress installs.

Thanks to a report from [Stuart Sequeira](http://profiles.wordpress.org/StuartSequeira), I realized I'd forgotten to re-add subdirectory support when I rewrote it in v1.0. I also regenerated the pot file to make sure the strings are included.

In short: Download Shortcode provides a shortcode for wrapping media links that forces them to download. It's great for providing easily-downloadable MP3, jpg, mp4 or other media file types.

### Want to contribute?

Download Shortcode is in active development on [GitHub](https://github.com/DrewAPicture/download-shortcode "Download Shortcode on GitHub") too, so if you'd like to contribute, pull requests are welcome.
