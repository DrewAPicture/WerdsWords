# WerdsWords

The personal blog of Drew Jaynes. Built with [Eleventy](https://www.11ty.dev/).

## Building from source

Requires Node.js ≥ 18.

```bash
npm install
```

**Local dev server** — builds the site and watches for changes at `http://localhost:8080`:

```bash
npm start
```

**Production build** — writes static output to `_site/`:

```bash
npm run build
```
