Tonight I released [Jazzy Generator Tag 5.6.0](http://werdswords.com/plugins/jazzy-generator-tag/), adding support for WordPress 5.6.

If you're unfamiliar with Jazzy Generator Tag, it's a silly little plugin I wrote a couple of years ago to zhuzh up the generator tag that gets added to the HTML source advertising the installed version of WordPress.

The plugin filters the standard "WordPress 5.6" (or whatever string) to include the jazzer for the currently installed version.

For WordPress 5.6, [the jazzer was Nina Simone](https://wordpress.org/news/2020/12/simone/). So the generator tag running on WerdsWords right now reads, "WordPress 5.6.1 to the sounds of Nina Simone." Go ahead, check out the source and take a look!
